## Shared art direction

Reproduction brief: create an original polished stylized 3D cartoon bust for a friendly but incisive SEO council. Oversized expressive head, large lively eyes, smooth sculpted skin, simplified anatomy, warm studio lighting, clean clothing, shoulders fully within frame, centered front or slight three-quarter view. Transparent background. Consistent scale and framing across the council. No text, logos, watermark, chair, frame or scenery. Preserve recognizable public professional appearance from the supplied identity reference while remaining obviously illustrated. Avoid photographic skin texture and extreme caricature. One person only.

These are maintained reproduction briefs; generator-internal parameters and seeds are unavailable.

## Review and replacement

The first Darren output was rejected as too photographic and regenerated. Final portraits were checked for consistent cartoon treatment, clean transparency, face/shoulder framing, readable small-size silhouettes and legibility in the actual desktop/mobile room. No pixel editing was used to fabricate source portraits.

For a replacement, inspect a current public identity reference, use the shared direction plus the individual brief, and compare against an existing council illustration. Save only the reviewed final PNG, update this record and the expert's review date, run package validation, and inspect 320/390/768/1024/1440 px views.
